# Boss Fight Atlas

Открытая интерактивная энциклопедия механик боссов для гейм-дизайнеров. Каждый урок показывает, как собрать, объяснить, настроить и проверить один элемент боя.

[Открыть атлас](https://polyakovin.github.io/gamedev-boss-fights/ru/) · [English README](README.md) · [Как участвовать](CONTRIBUTING.md)

Первый урок — **[«Таран»](https://polyakovin.github.io/gamedev-boss-fights/ru/mechanics/charge/)**. Сравните две тестовые траектории, остановите анимацию и разберите слежение, фиксацию направления, столкновение и восстановление. В этом варианте после фиксации направления босс уже не может повернуть.

Атлас доступен на восьми языках: английском, русском, упрощённом китайском, хинди, бенгальском, испанском, арабском и японском. Первые версии переводов ожидают независимой проверки людьми, свободно владеющими соответствующим языком.

## Небольшой вклад тоже полезен

На странице урока нажмите «Улучшить страницу», исправьте JSON в GitHub и отправьте PR из своего форка. Можно исправить одну формулировку или перевод: готовить целую механику и переводить все восемь языков не требуется. Сохраняйте ключи JSON, порядок массивов и индекс правильного ответа.

## Локальный запуск

Нужны Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Откройте [localhost:4173/gamedev-boss-fights/](http://localhost:4173/gamedev-boss-fights/). После правок выполните `npm run build` во втором терминале и обновите страницу: автоматического пересоздания сборки нет.

```sh
npm run format:check
npm run check
npx playwright install chromium
npm run test:browser
```

`check` проверяет структуру материалов, запускает тесты Node и собирает сайт. Браузерные тесты запускаются отдельно; Chromium достаточно установить один раз.

`npm run format` применяет форматирование закреплённой версией Prettier, а `npm run format:check` проверяет его без изменения файлов.

Новый черновик создаётся командой `npm run new:mechanic -- your-mechanic`. Черновики можно дополнять несколькими PR: они не попадают на сайт. Для публикации нужны все восемь переводов с `sourceVersion`, совпадающим с `meta.contentVersion`, зарегистрированная анимация и отсутствие незаполненных `TODO:`.

Сайт собирается статическим генератором Node без фреймворка. Тексты находятся в `content/mechanics/`, интерфейсные переводы — в `locales/`, код и стили — в `lib/` и `src/`. Результат в `dist/` не коммитится.
